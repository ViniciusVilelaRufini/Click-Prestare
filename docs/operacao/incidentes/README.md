# Pós-incidentes

Um arquivo por incidente: `AAAA-MM-DD-titulo.md`, preenchido em até 5 dias úteis (sem culpados). Processo em `../melhoria-continua.md` e `../plano-resposta-incidentes.md`. Não registrar segredos nem dados pessoais.

## Modelo

```
# Incidente: [título]
Início e fim:                 Duração:
Impacto (quem, o quê):
Detecção (alarme, cliente, acaso) e tempo até detectar:
Linha do tempo:
Causa raiz (5 porquês):
O que funcionou:
O que não funcionou:
Ações (dono, prazo):
 - [ ] correção
 - [ ] prevenção
 - [ ] detecção (alarme ou teste novo)
Runbook ou documento a atualizar:
Cliente avisado? Quando?
```

## Registro

Nenhum incidente registrado até a data deste documento.
